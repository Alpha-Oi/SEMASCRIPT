# 03_ROADMAP

## Общая цель roadmap
Перевести SEMASCRIPT из концептуально сильной идеи в рабочую систему с проверяемым ядром, профилями, тестами и прототипами.

## Порядок фаз

- identity
- architecture map
- current status
- scope v0.1

### Phase 1 — Core Specification
- классы узлов
- роли
- focus rule
- scope rule
- canonical form
- базовая валидность

### Phase 2 — Pattern / Time / Invariant Pack
- `SPR`
- `GEN`
- `PAL`
- `TIME:*`
- `ZSUM / NZSUM / BAL`

### Phase 3 — Test Pack
- positive / negative cases
- error classes
- manual validation checklist

### Phase 4 — Human Profile
- сокращения
- omissions
- shorthand
- ambiguity limits
- Human → Core

### Phase 5 — Exec Profile
- executable grammar
- typing
- scope
- validation
- serialization

### Phase 6 — Tooling MVP
- parser
- validator
- converters

### Phase 7 — Glyph Architecture
- shape classes
- modifiers
- frame markers
- layout rules

### Phase 8 — Reference Corpus / Pilots
- corpus
- пилотные домены
- сравнение плотности и ясности

### Phase 9 — v1 Decision Gate
- стабилен ли Core
- читаем ли Human Mode
- валиден ли Exec Mode
- не ломает ли визуальный слой семантику
